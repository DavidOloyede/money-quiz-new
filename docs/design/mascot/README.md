# Omer: construction references

These are **construction references**, not the commissioned master art (still
to come; it will live here too). Every drawing is generated by `omer.cjs`, a
small function that returns SVG markup for any view, pose or outfit on a 200 ×
200 grid where one unit is the rim width.

- `svg/`: 4 views, 8 poses and 9 outfits as editable SVGs (`node export-svgs.cjs`).
- `omer-model-sheet.html`: the review page published as a Claude artifact
  (`node build-model-sheet.cjs`).

The rules for drawing and using Omer are in `docs/DESIGN.md`; the plan for
building him into the app is in `docs/design/HANDOFF-design-system.md`.
